# E-Commerce Order Management System

## Project Description

The E-Commerce Order Management System is a DBMS project developed using MySQL. It manages customers, addresses, product categories, products, orders, order items and payments in an organized relational database.

## Technologies Used

- MySQL
- SQL
- GitHub

## Main Tables

The database consists of seven main tables:

1. Customer
2. Address
3. Category
4. Product
5. Orders
6. Order_Item
7. Payment

## Database Operations

The project includes:

- DDL operations
- DML operations
- DQL operations
- CRUD operations
- JOIN operations
- Aggregate functions
- Subqueries
- Views
- Relational set operations

## Database Constraints

The following constraints are used to maintain data integrity:

- PRIMARY KEY
- FOREIGN KEY
- NOT NULL
- UNIQUE
- CHECK
- DEFAULT
- AUTO_INCREMENT

## Project Modules

- Customer and Address Management
- Category and Product Management
- Order Management
- Order Item Management
- Payment and Transaction Management
